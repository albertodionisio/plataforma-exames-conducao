Teste do player EmbedMovies

Esta página demonstra como incorporar um player externo numa página HTML usando um iframe.

Identificador IMDb: tt0462499 Abrir o endereço original

Teste de partilha: o primeiro botão abre o menu nativo do Android para escolher uma aplicação, incluindo um gestor de downloads se este aceitar links de páginas. O link partilhado é o endereço do player, não um ficheiro de vídeo directo. O EmbedMovies documenta integração por iframe e não publica uma API de download; por isso, a partilha pode abrir a página no gestor, mas não garante que o 1DM consiga obter o vídeo. Esta página não tenta contornar protecções nem extrair streams de terceiros.
