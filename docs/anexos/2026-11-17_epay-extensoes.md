# ePay: página "Extensões" (2026-11-17)

Imagem: `2026-11-17_epay-extensoes.png` (foto de perfil tapada, o repositório é público).

Conteúdo: `painel.epay.co.mz/integracoes`, título "Extensões: Liga a EPay às ferramentas que já usas." Três opções:
- **Tasky Chat**: envia links de pagamento nas conversas de WhatsApp e avisa quando o cliente pagou.
- **API**: liga qualquer sistema à ePay com chaves e webhooks. É a opção para ligar a plataforma de exames.
- **WooCommerce**: recebe pagamentos numa loja WordPress e sincroniza produtos. Não serve para este projecto (não é WordPress).

Nota: as chaves da API não se guardam no repositório. Vão para as variáveis de ambiente do alojamento.
