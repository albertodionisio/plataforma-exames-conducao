# Login com Google: selector de contas (2026-11-17)

Imagem: `2026-11-17_login-google-selector-de-contas.png` (emails tapados antes de subir, o repositório é público).

Conteúdo: ecrã `accounts.google.com`, "Selecione uma conta", "Continuar para plataforma-exames-conducao.firebaseapp.com", lista de contas Google do telemóvel e "Usar outra conta".

Significado: o botão "Continuar com Google" da plataforma abre o selector de contas. O domínio está aceite pelo Firebase Authentication. Falta confirmar que, depois de escolher a conta, o utilizador entra na plataforma.
