# DEF-003 — Notificações

## Implementação
- A página de Definições permite activar notificações locais apenas após um clique explícito em «Activar notificações».
- O pedido usa a API Notification do navegador e só é tentado em contexto seguro (HTTPS ou localhost).
- São tratados os estados: navegador sem suporte, contexto inseguro, permissão por conceder, concedida e recusada/bloqueada.
- A preferência de activação do ESTRADA é guardada localmente em `localStorage` (`estrada.notificacoes.ativas`).
- O utilizador pode desactivar os avisos do ESTRADA sem confundir essa acção com a revogação da permissão global do navegador.
- Existe uma acção explícita para enviar uma notificação de teste.
- O estado é actualizado ao regressar o foco à página.

## Limites deliberados
- As notificações só são apresentadas enquanto a aplicação está aberta; não há service worker, push, backend nem envio em segundo plano.
- Não foram criados alertas fictícios de expiração de subscrição, resultados ou lembretes: essas funções dependem de conta, dados e/ou serviços que ainda não existem.
- «Desactivar avisos» desactiva a aplicação neste dispositivo, mas não revoga a permissão global do navegador.
